# kalexnolasco.github.io

Personal site of Alex Nolasco, served by GitHub Pages at <https://kalexnolasco.github.io/>.

Plain HTML, CSS and JavaScript, no build step: edit `index.html` (Spanish text) and `assets/main.js` (English text),
push to `main`, and Pages publishes it. Star counts refresh from GitHub's API in the browser.

Local preview:

```bash
python3 -m http.server 8777 --directory .
```
